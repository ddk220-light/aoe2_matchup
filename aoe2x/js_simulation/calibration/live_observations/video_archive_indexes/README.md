# Recorded-game result index intake

Copy original `run.json` archive indexes here from the recording computer, one
dated/archive-named directory per source. Also preserve available chapter result
tables, catalogs, correction/source histories and missing-recording indexes.
See [Matchup Table v3](../../../../../MATCHUP_TABLE_V3.md#add-the-real-in-game-video-results-from-another-computer)
for source locations, upload steps, context checks and the current data-only scope.

No original recorded-game result indexes have been supplied in this directory at
the handoff cutoff. This README is a destination, not a claim that those outcomes
have been imported or independently verified. Keep media external initially;
retain its original references. Do not put diagnostics, guessed outcomes or old
simulation summaries into a recorded-game results ledger.
