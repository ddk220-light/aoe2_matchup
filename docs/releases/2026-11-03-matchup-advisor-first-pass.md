# Matchup Advisor first-pass release

The old advisor loaded the legacy civilization roster and ran Python combat on demand. It now reads the published provisional campaign: 56 civilizations, 555 land-unit variants, 1,540 civilization pairs and 151,223 displayed cells. Forecasts stay explicitly estimated; the page does not start fights or silently treat predictions as observations.

The Flask and Astro pages share the same advisor controller and styles. The existing two-civilization selection and deselection flow remains, with updated comparison cards, canonical shared unit icons, the three new civilization emblems, visible resource costs, observed/inferred/estimated badges, army-count details and responsive light/dark styling. Existing siege reference cards and their published ranks are retained separately; rankings, combat mechanics, navigation and page metadata are unchanged.

`data/golden/civ_matchups_first_pass.db` is a read-only serving artifact, generated by `scripts/build_advisor_first_pass.py` from the immutable bundle at simulation commit `207c31283c70db1f6ebea4ae93535c98dfe86777`. Its adjacent metadata file records the original bundle hashes and serving-artifact checksum. Compressed profile provenance retains original contexts, forecasts, rule/source hashes, failures/contested flags and cross-engine replay references. Display reversal changes only the viewer perspective of the same saved fight.

The advisor component exports a catalog and 56 versioned civilization slices. The browser reads only the selected slice through the existing immutable data delivery; read-only API endpoints expose the same catalog, matchups and provenance. The 45,896 first-pass predictions, including 19 repaired-engine projections, remain unvalidated. No new scoring, forecast training, bulk replay or exhaustive validation is included.
